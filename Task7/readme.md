## Висновок

У ході виконання завдання було реалізовано симуляцію кидання двох гральних кубиків методом Монте-Карло.

Було проведено велику кількість ітерацій, після чого підраховано частоти появи кожної можливої суми (від 2 до 12) та обчислено ймовірності.

Отримані результати порівняно з аналітичними значеннями для двох кубиків (36 можливих комбінацій). Було встановлено, що при збільшенні кількості симуляцій результати Монте-Карло наближаються до теоретичних значень.

Таким чином, метод Монте-Карло підтвердив правильність аналітичного розподілу ймовірностей.
